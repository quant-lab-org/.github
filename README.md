# `.github` — quant-lab-org community-health defaults

Org-level GitHub defaults for `quant-lab-org`. The `ISSUE_TEMPLATE/` forms are **copied byte-for-byte from `goldenmasters/.github`** (the golden source) — do not edit them here. Any change lands at the golden first and is re-copied.

- `ISSUE_TEMPLATE/task.yml` — the Task form.
- `ISSUE_TEMPLATE/epic.yml` — the Epic form.
- `ISSUE_TEMPLATE/config.yml` — turns off the blank-issue option.

GitHub applies these to every repo in `quant-lab-org` that has no templates of its own, so a GHI typed into the UI in any such repo arrives in the fleet's card shape.

Source: [`goldenmasters/.github`](https://github.com/goldenmasters/.github).
